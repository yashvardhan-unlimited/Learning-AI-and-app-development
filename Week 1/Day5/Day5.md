# Project — Tone Rewriter CLI

A Python CLI tool that rewrites a paragraph into different tones using the OpenAI API.

## Generates

- Formal Version
- Casual Version
- Persuasive Version

---

# Concepts Practiced

## Few-shot Prompting
Providing examples to guide the model’s responses.

## Role Prompting
Assigning a specific role to improve output quality.

## Output Constraints
Controlling response format, structure, and style.
